MEHWISH — PROFESSIONAL PORTFOLIO
Open index.html in Chrome to preview. Before sharing publicly:
1. Open script.js and set CONTACT_EMAIL to your real professional email.
2. Confirm the two live project URLs and add any additional URLs you own.
3. Project visuals are labeled illustrative previews, not screenshots. Replace them with actual screenshots when available.
4. Review project descriptions and remove anything you do not wish to advertise.
5. Upload index.html, style.css and script.js to your own portfolio hosting folder. Do not overwrite an existing client website.
The inquiry form opens the visitor's email application once configured; it does not send messages itself. No database or API keys are needed. Google Fonts is optional; local fallbacks are included.
